通用线性控件图标使用 Iconoir 官方 SVG 素材，保持 24px 视图、1.5px 描边、圆端点和圆连接。

当前覆盖 `refresh-cw`、`check`、`x`、`chevron-down`、`moon`、`sun`、`pin`、`panel-left`、`trending-up`、`layout-list` 和 `help-circle`。

历史面板最小化态的葫芦图标属于产品记忆符号，不纳入通用控件图标替换范围；声骸效果图、favicon 等业务或品牌素材也不使用 Iconoir 替代。
