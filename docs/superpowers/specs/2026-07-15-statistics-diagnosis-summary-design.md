# Statistics Diagnosis Summary Design

**Date:** 2026-07-15
**Status:** Approved design, pending implementation plan

## Goal

收敛统计页“统计诊断”页头与“样本可信度”卡片的信息层级。页面头负责回答“现在处于什么状态”，可信度卡片负责解释“判断依据是什么、距离下一阶段还有多远”，不再用大号绿色结论占据卡片左侧。

## Scope

本设计只调整已有样本时的统计页摘要和样本可信度卡片，不修改：

- 副词条分布偏差卡片及其 `pp` 语义。
- 统计 API、presentation 阶段计算或数据结构。
- 工作台、模型评估页和全局导航。
- 零样本初始化、加载状态或首次使用引导。

## Problem

当前“样本可信度”卡片将“当前结论 / 起步观察”做成大号绿色标题，同时把“规则基线 · 当前阶段”悬置在中间、阶段进度放在最右侧，导致三组信息缺少共同基线和清晰关系。统计诊断页头右侧为空，也没有复用模型评估页已经建立的状态摘要语言。

## Approved Layout

### Statistics diagnosis header

页头改为左右结构：

- 左侧保留“统计诊断”和区域级样本说明，例如“基于 286 条样本，当前偏差仅作趋势提示。”
- 右侧只放两个摘要胶囊：
  - 状态胶囊：绿点加“起步观察”。文字来自现有 `statsReliabilityText(totalSamples)`，绿色表示当前统计阶段，不表示成功。
  - 阶段胶囊：“阶段 0–500 条”。范围来自现有样本阶段数据。

不得为了填满右侧空间增加第三个胶囊。特别禁止加入“最大偏差 +18.18pp”，因为它与分布偏差卡重复，并且在低样本阶段容易被误读为稳定结论。

页头摘要在桌面端右对齐并与标题顶部对齐；860px 以下移动到标题说明下方并左对齐，允许自然换行。

### Sample reliability card

卡片标题栏只保留“样本可信度”，移除当前放在标题右侧的阶段和“规则基线主导”胶囊。

卡片正文顶部使用一个无额外边框、无独立底色的双列解释行：

- 左列：
  - 标签：“判断依据”。
  - 主要值：现有阶段驱动文案，例如“规则基线主导”。
  - 次级说明：“当前阶段的主要解释来源”。
- 右列：
  - 标签：“阶段进度”。
  - 主要值：`286 / 500`。
  - 次级说明：`57.2% 完成，距「总体偏差」还差 214 条`。

删除卡片中的“当前结论”标签和大号“起步观察”文字。结论只在页面头状态胶囊出现一次，阶段范围也只在页面头出现一次。解释行之后使用现有 1px 分隔线，再进入完整阶段轴。

### Visual hierarchy

- 页面头状态胶囊与模型评估状态栏使用相同的高度、边框、圆角、标签/数值比例和状态点语言，但统计页仍由自己的 feature CSS owner 管理。
- 卡片内“规则基线主导”使用紧凑强调字号，不再与数据大数字竞争。
- `286 / 500` 继续使用数据字体和稳定数字宽度，作为解释行唯一的大号数值。
- 不新增嵌套卡片、阴影、渐变文字或装饰性色条。
- 深色模式保持相同 DOM 和信息顺序，只做现有语义色映射。

## Data and component boundaries

`StatisticsView.vue` 继续作为唯一页面 owner，复用已有：

- `statsReliabilityText(totalSamples)` 生成页头状态。
- `sampleStageRangeText` 生成页头阶段范围。
- `sampleStageDriverText` 生成卡片判断依据。
- `sampleStageStatus`、`sampleStagePercentText` 和 `sampleStageGoalText` 生成阶段进度。

不新增 API、store、持久化状态或跨页面共享组件。只在确认评估页状态胶囊与统计页需要长期共享时，才另行提取共享样式；本轮不扩大重构范围。

## Accessibility

- 页头胶囊组使用“统计摘要”作为可访问名称。
- 绿点设为 `aria-hidden="true"`，状态意义必须由“起步观察”文字完整表达。
- 阶段进度、剩余样本和阶段轴继续保留现有可访问说明。
- 窄屏换行不得改变 DOM 阅读顺序：标题、说明、摘要胶囊、卡片标题、判断依据、阶段进度、阶段轴。

## Tests and acceptance criteria

- 统计页头存在仅含“起步观察”和阶段范围的摘要组。
- 页头和卡片均不出现“最大偏差”摘要胶囊。
- “起步观察”不再作为卡片内大号结论出现。
- 阶段范围不在页头和卡片标题栏重复。
- 卡片解释行包含判断依据、阶段驱动、阶段进度、当前/目标样本数和剩余样本数。
- 1280px 浅色与深色模式中，页头摘要和标题对齐；860px、600px、520px 下无页面级横向溢出。
- 完整前端测试、生产构建和 `git diff --check` 通过。

## Out of scope

零样本时是否显示默认阶段、引导动作或占位卡片继续留待后续初始化方案讨论，本设计不提前定义该行为。
