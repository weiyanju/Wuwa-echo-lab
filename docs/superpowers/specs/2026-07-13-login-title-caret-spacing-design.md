# 登录标题打字光标间距设计

**日期：** 2026-07-13

**适用范围：** `WuwaFrontend` 登录页标题“欢迎回家，漂泊者”的打字光标

## 问题

当前标题使用 `border-right` 表达 4px 打字光标。光标直接贴在标题内容盒末端，与最后一个汉字的视觉距离不足，削弱了打字机效果，并让末字与光标产生粘连感。

## 设计决定

- 保留现有 4px 蓝色打字光标、逐字显示和闪烁节奏。
- 在标题文字与光标之间增加 `0.14em` 的行末内边距；桌面 56px 标题下约为 8px，并随批准的响应式字号等比变化。
- 使用 CSS 自定义属性命名该间距，避免魔法数散落，并让测试能够锁定设计意图。
- 不在标题文案中插入空格或不换行空格，不改变可访问名称和打字步数。
- 520px 以下继续关闭打字光标，同时把光标间距归零，避免移动端标题换行后留下无意义空白。
- `prefers-reduced-motion` 继续关闭打字与闪烁动画；标题内容必须完整可见，光标间距不影响可读性。

## 实现边界

仅修改登录页 feature CSS 和对应静态回归测试。不调整标题字号、字重、文案、动画时长、登录布局或其他页面动效。

## 验收标准

1. 桌面端光标与末字之间约有 8px 视觉间距，光标仍停在文字末端并正常闪烁。
2. 打字动画完成后标题无截断，光标不会移动到整列右侧。
3. 520px 以下标题正常换行，不显示光标，也不保留光标间距。
4. reduced-motion 模式下标题立即完整显示，且没有打字或闪烁动画。
5. 前端定向测试、全量测试和生产构建通过。
