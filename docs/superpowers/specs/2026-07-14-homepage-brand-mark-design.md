# 首页品牌标识与浏览器图标设计

## 1. 目标

将 Web 首页顶部现有的方形状态图标与 `Tethys System | 泰缇斯枢纽` 文案，替换为参考图中的蓝色圆环圆点图标与全大写 `TETHYS` 字标；同时让浏览器标签页使用同一枚品牌图标。

本次改动只统一品牌识别，不改变首页结构、认证流程、工作台布局或浏览器标签标题。

## 2. 已确认范围

- 首页顶部品牌展示为“蓝色圆环圆点图标 + `TETHYS`”。
- 移除首页顶部品牌中的 `Tethys System | 泰缇斯枢纽`。
- 浏览器 favicon 替换为同一枚蓝色品牌图标。
- 浏览器标签标题继续保持 `泰缇斯枢纽`。
- 登录后的工作台顶部品牌、加载状态与 UID 绑定页不在本次改动范围内。

## 3. 设计方案

新增一个独立、透明背景的 SVG 品牌图标资源。图形由品牌蓝色描边圆环和右上方实心圆点组成，保持参考图的几何关系，并使用清晰的小尺寸视图框以适配首页与 favicon。

首页通过图片元素引用该图标，`TETHYS` 继续使用真实文本：

- 图标提供空替代文本并由父级品牌文本承担可访问名称，避免重复朗读。
- 字标沿用现有 `--font-latin`、品牌字距和真实字重。
- 保持现有顶部导航高度、对齐与响应式结构，不因品牌替换造成布局跳动。
- 图标与文字之间使用现有品牌间距体系，颜色不引入新的视觉 token。

浏览器 favicon 直接引用同一个 SVG，避免首页与标签页形成两套相似但不一致的实现。

## 4. 代码归属

- 品牌 SVG 属于公开静态资源，放在 `WuwaFrontend/public/`。
- 首页品牌 DOM 保持在 `WuwaFrontend/src/features/auth/LoginView.vue`。
- 首页品牌样式保持在 `WuwaFrontend/src/styles/features/auth.css`。
- favicon 与标签标题配置保持在 `WuwaFrontend/index.html`。

不新增 UI 框架、组件抽象或全局状态。

## 5. 状态与异常处理

SVG 是随前端构建发布的本地资源，不依赖网络或第三方 CDN。即使图标加载异常，真实文本 `TETHYS` 仍可显示并保留产品识别。

本次没有新增交互状态、数据流或错误状态。

## 6. 验证

自动化验证：

- 先增加会失败的静态结构测试，要求首页引用共享品牌 SVG、显示 `TETHYS`，且不再显示原完整品牌文案。
- 增加 favicon 引用和浏览器标题保持不变的测试。
- 实现后运行命中的前端测试与完整前端构建。

视觉验证：

- 桌面端确认图标比例、字标间距和导航垂直对齐接近参考图。
- 窄屏确认品牌不换行、不挤压右侧状态，也不产生横向溢出。
- 浏览器确认标签页显示新的蓝色图标，标题仍为 `泰缇斯枢纽`。

## 7. 验收标准

- 首页顶部只显示蓝色圆环圆点图标与 `TETHYS`。
- 图标造型、蓝色与参考图一致，不保留原方形图标。
- favicon 使用同一品牌 SVG，不再显示原紫色闪电图标。
- 浏览器标签标题仍为 `泰缇斯枢纽`。
- 页面结构、登录流程和其他品牌入口没有非预期变化。
- 命中测试与前端构建通过，桌面和窄屏截图无明显视觉回归。
