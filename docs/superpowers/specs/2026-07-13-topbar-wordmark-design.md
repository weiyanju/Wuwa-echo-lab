# 顶部导航字标优化设计

日期：2026-07-13

## 目标

解决顶部导航左上角 `Tethys System` 在全中文工作台中显得突兀的问题，同时保留英文品牌识别和现有台头结构。

## 已确认方案

采用“极简英文品牌”方案，仅将可见字标从 `Tethys System` 调整为 `TETHYS`。

- 使用全大写短英文专名，删除泛化的 `System`。
- 字号约 16px，字重 700，添加轻微字距，避免现有粗黑系统标题感。
- 将现有渐变圆点替换为单色“轨道节点”标志：细蓝色圆环配一个实心蓝色节点。
- 标志使用泰缇斯蓝，不使用渐变、发光或装饰动画。
- 字标与标志保持约 10px 间距，整体点击区域和导航高度不变。
- 链接的无障碍名称保留为“返回 Tethys System 工作台”，避免缩写影响辅助技术理解。

## 保持不变

- 顶部导航的尺寸、圆角、粘性定位、阴影和背景。
- “工作台 / 统计 / 评估”导航及其选中状态。
- UID 切换器、主题按钮和退出按钮。
- 下方“你好，漂泊者”欢迎区、三个指标及其数据逻辑。
- 移动端的导航堆叠方式和业务信息顺序。
- 登录页及其他位置的产品全称，本次不做全局品牌重命名。

## 视觉状态

- 浅色模式：蓝色圆环与节点，深墨色 `TETHYS`。
- 暗色模式：标志继续使用品牌蓝，文字映射到现有高对比前景色。
- Hover：沿用现有字标链接反馈，不增加位移或缩放。
- Focus：保留清晰键盘焦点轮廓，且不依赖颜色单独表达。

## 响应式与边界情况

- 短字标会减少横向占用，不改变现有断点。
- 520px 和 860px 断点下沿用当前顶部导航布局，不额外隐藏品牌名。
- 标志由 CSS 绘制，不增加图片请求，也不存在资源加载失败状态。

## 实施范围

- 更新 `WuwaFrontend/src/App.vue` 中工作台顶部导航的可见字标与无障碍标签。
- 更新 `WuwaFrontend/src/styles/shell.css` 中 `.wordmark` 和伪元素样式。
- 更新相关前端测试，验证可见文案、无障碍名称、标志形态和暗色模式映射。

## 验收标准

1. 工作台顶部左上角显示 `TETHYS`，不再显示可见的 `Tethys System`。
2. 新标志为单色圆环与节点，不包含渐变。
3. 顶部导航及下方欢迎摘要的结构、尺寸和业务文案不发生变化。
4. 字标链接仍可返回工作台，键盘可聚焦，并提供完整无障碍名称。
5. 浅色、暗色和现有响应式断点下均保持清晰、无溢出。
6. 前端测试和生产构建通过。
