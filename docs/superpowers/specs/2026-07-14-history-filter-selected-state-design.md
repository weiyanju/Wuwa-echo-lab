# 历史声骸筛选器选中态设计

日期：2026-07-14
状态：用户已确认
范围：Web 工作台历史声骸浮动面板

## 1. 背景

历史声骸面板当前把筛选项渲染为“勾选图标 + 文本 + 数量”。图标节点始终存在，未选中时仅将透明度设为 `0`，因此每个筛选项都会永久占用一段左侧空间。选中“全部”后，这个勾选符号又容易被理解为复选框，和实际的单选筛选逻辑不一致。

筛选器已有 `aria-pressed`，其状态语义不依赖可见勾选图标。用户确认采用视觉方案 A：删除额外符号，通过整枚胶囊的实色填充和数量徽标反色表达选中状态。

## 2. 目标

- 移除勾选图标和左侧预留空位。
- 让当前筛选项一眼可辨，同时保持面板紧凑。
- 保留“全部 / 当前 / 待强化 / 已强化 / 弃置”的现有状态色语义。
- 选中态不能只依赖细微色差；整面填充、文字反差和数量徽标共同表达状态。
- 切换筛选项时不发生宽度、边框厚度或位置跳动。
- 保持现有单选筛选逻辑、数量计算、记录排序和认证数据流程不变。

## 3. 非目标

- 不调整筛选分类、标签文案或计数口径。
- 不修改历史记录卡片、状态徽标或当前记录焦点环。
- 不重排历史面板标题、操作按钮和记录数量。
- 不引入新的全局颜色体系、图标或动画语言。
- 不改变历史面板的固定、展示、最小化和拖拽逻辑。

## 4. 结构

每个筛选按钮只保留两个可见内容：

1. 筛选标签。
2. 数量徽标。

`FloatingHistoryPanel.vue` 删除 `history-filter-selected-icon` 节点及其图标依赖。按钮继续使用原生 `button`、`type="button"` 和 `aria-pressed`，点击后仍只更新唯一的 `historyFilter` 值。

选中和未选中状态使用相同的最小高度、内边距、间距、圆角和 `1px` 完整边框。不得通过新增图标、改变边框厚度、缩放或位移制造选中反馈。

## 5. 视觉规则

### 5.1 未选中状态

- 保留现有低饱和语义色边框和浅色背景。
- 标签与数量均使用该分类的深色语义文字。
- 数量徽标继续使用更浅的内层表面，维持可比较数字的稳定位置。
- “全部”使用中性灰蓝；其余四项继续使用蓝、琥珀、绿和红。

### 5.2 选中状态

选中项整枚胶囊使用对应分类的实色填充：

| 筛选项 | 胶囊填充 | 标签文字 | 数量徽标 |
| --- | --- | --- | --- |
| 全部 | 深灰蓝 | 浅色 | 浅灰蓝底、深灰蓝数字 |
| 当前 | 主蓝色 | 浅色 | 浅蓝底、深蓝数字 |
| 待强化 | 中等琥珀色 | 深棕色 | 浅琥珀底、深棕数字 |
| 已强化 | 深绿色 | 浅色 | 浅绿底、深绿数字 |
| 弃置 | 深红色 | 浅色 | 浅红底、深红数字 |

琥珀色选中态不能机械使用白字；必须根据实际对比度使用深棕文字。其他状态也应以最终计算对比度决定文字明暗，标签和数字正文应达到 WCAG AA 的 `4.5:1` 对比度目标。

选中项不添加宽阴影、发光、外扩边框或额外装饰。实色表面本身就是主要反馈。

### 5.3 悬停、按下和焦点

- 未选中项悬停时只轻微加强边框和底色。
- 选中项悬停时在同一语义色内小幅加深，不改变几何尺寸。
- 按下状态不缩放、不下沉、不位移。
- `:focus-visible` 使用独立的完整焦点环和间距，不能复用选中边框，也不能只依赖颜色。
- 鼠标悬停、选中和键盘焦点必须能同时成立，不互相覆盖。

### 5.4 动效

只允许 `border-color`、`background-color`、`color` 和数量徽标颜色使用约 `160ms` 的 ease-out 过渡。禁止对 `width`、`padding`、`transform` 或布局属性做动画。

`prefers-reduced-motion: reduce` 下可直接关闭这些颜色过渡，筛选结果和焦点反馈保持即时可见。

## 6. 深色主题

深色主题沿用相同的结构与语义色映射，但需要降低极亮颜色的刺激度：

- 未选中项使用深色表面和克制的语义边界。
- 选中项保持实色填充，亮度足以从面板背景中分离，但不得产生霓虹或发光效果。
- 数量徽标必须与选中胶囊形成明确的内外层次，并保持文字对比度。
- 五种筛选项在深色主题中都要逐项检查，不能只验证“全部”。

## 7. 响应式与布局

- 保留现有 `flex-wrap` 行为和筛选项顺序。
- 删除图标后，按钮宽度自然收紧，不使用固定宽度补偿。
- 选中前后按钮宽度必须相同，换行位置不能因状态切换改变。
- 在历史面板最窄支持宽度下，不出现文本裁切、数量换行、横向滚动或按钮重叠。

## 8. 可访问性

- 保留每个按钮的 `aria-pressed`，其值必须和 `historyFilter` 同步。
- 删除的勾选图标不需要替代文本；标签和按钮状态已提供完整语义。
- 键盘用户可以按现有 Tab 顺序访问所有筛选项，并通过 Enter 或 Space 切换。
- 选中态由完整填充、前景反差和数量徽标反色共同表达，在灰度环境下仍应明显区别于未选中项。
- 焦点环与选中态是两个独立状态，不能因选中而隐藏键盘焦点。

## 9. 代码归属

- `WuwaFrontend/src/features/history/FloatingHistoryPanel.vue`：删除选中图标结构和不再需要的图标引用，保留筛选行为与 `aria-pressed`。
- `WuwaFrontend/src/styles/features/history.css`：删除图标占位规则，收紧按钮间距，并定义五种实色选中状态及深色主题对应状态。
- `WuwaFrontend/src/features/history/FloatingHistoryPanel.test.js`：验证组件结构、单选状态和紧凑布局契约。
- `WuwaFrontend/src/design-state-accent.test.js`：把“必须显示勾选标记”的旧守卫改为“不得渲染额外选中图标，并通过完整实色胶囊提供非微弱选中差异”。
- `docs/web-workbench-ui-guidelines.md`：实施时同步历史筛选器的长期规则。

组件仍归属 history feature；不得把筛选样式移回 `App.vue` 或全局入口。

## 10. 测试与验收

### 10.1 自动化

- 组件不再包含 `history-filter-selected-icon` 或对应图标样式绑定。
- 每个筛选按钮继续提供 `aria-pressed`，点击逻辑仍是互斥单选。
- CSS 中五种 `.active` 状态都有完整实色填充和对比文字规则。
- 选中与未选中状态保持相同边框厚度和几何尺寸。
- hover/active 不使用 `translate`、`scale` 或布局属性动画。
- 深色主题覆盖五种筛选状态。
- 现有历史记录过滤、记录选择、最小化和拖拽测试保持通过。

### 10.2 浏览器验收

- 分别选中“全部 / 当前 / 待强化 / 已强化 / 弃置”，每一项都能立即辨认且没有图标空位。
- 切换时筛选器不跳动、不重排，记录数量与列表结果正确更新。
- 亮色和深色主题下逐项检查文字与数量徽标对比度。
- 键盘焦点在选中项和未选中项上都清晰可见。
- 历史面板窄宽度下换行稳定，无横向溢出。
- 页面控制台无新增警告或错误。

## 11. 与既有决策的关系

本规范明确替代 `docs/superpowers/specs/2026-07-13-web-state-accent-polish-design.md` 中“历史筛选激活项显示勾选标记”的局部决定。旧规范仍作为当时移除彩色侧条的历史记录保留；新的纠正仅针对历史筛选器选中标记，不恢复单侧条，也不改变其他页面已经采用的勾选语义。
