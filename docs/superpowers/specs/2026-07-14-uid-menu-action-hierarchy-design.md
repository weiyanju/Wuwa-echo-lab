# UID 菜单操作层级设计

## 背景

UID 菜单中的“退出登录”先后尝试过分隔线纯文字、弱底色圆角菜单行以及居中菜单行。实际页面对照表明，问题不在单独的文字对齐，而在账号行、添加入口和退出操作连续形成三个同权重圆角块。用户最终确认将退出操作降为独立页脚命令，同时保留“确认添加”的单色主按钮设计。

## 已确认方向

用户当前最终确认：

- “添加 UID”保留完整宽度和居中文字，使用弱蓝实线边框与弱蓝底色，不再使用虚线边框；“确认添加”继续使用泰缇斯蓝单色实底、冷白文字、12px 圆角、无渐变、无投影。
- “退出登录”进入菜单底部独立页脚区，靠右显示为 13px / 500 的低频文字命令；按钮保留至少 44px 点击高度，但默认不显示独立边框和底色。
- 两个操作都保持纯文字，不添加图标。
- 菜单定位改为锚定 `UidSwitcher` 自身，使右边缘与 UID 胶囊对齐，不再跟随旁边的主题按钮；UID 数据排版、新增输入、确认按钮和业务行为保持不变。

## 交互状态

- “确认添加”默认使用主蓝色；hover 只调整蓝色深浅，focus-visible 使用系统蓝色轮廓，disabled 保持尺寸并降低对比度。
- “退出登录”默认保持中性文字和透明背景；hover 与 focus-visible 使用危险文字和弱危险底色，键盘焦点继续使用系统轮廓。
- 退出动作的可访问名称保持“退出登录”，继续使用菜单项语义。
- 新增 UID 输入校验、提交事件、菜单关闭方式与焦点恢复行为不变。

## 布局与主题

- UID 菜单继续使用单列内容布局；退出页脚使用贯穿内容宽度的 1px 顶部分隔线和 8px 顶部内边距，页脚内部靠右放置紧凑命令按钮。
- 桌面端与窄屏使用同一结构，不增加新的响应式分支。
- 暗色主题保持同样的结构：添加入口使用弱蓝实线与底色，确认按钮仍为单色主蓝，退出命令默认透明；交互时切换为弱危险文字和背景。
