# 零样本极简入口设计

**状态：** 已确认

**日期：** 2026-07-16

**适用范围：** Web 统计诊断与模型评估的零样本正文

## 目标

零样本页只回答两个问题：当前页面以后会提供什么，以及用户现在应该做什么。它不提前解释阶段、里程碑、模型来源或远期阈值，不复用有数据时的信息密度。

## 共同结构

- 页面标题和中性“待录入”状态保留，便于跨页扫读。
- 标题下方只放一个居中的极简入口：价值句、必要说明、一个主按钮。
- 主按钮使用既有泰缇斯蓝 `var(--primary)`；黑色继续只承担主导航选中和最高层级文字。
- 零样本页面使用近白任务表面、1px 冷灰边界和无阴影结构；成功、警告、预测色均不出现。
- 不展示 kicker、阶段轴、步骤列表、里程碑、进度数字、预测来源或远期补充说明。

## 统计诊断

- 价值句：`这里将显示你的个人副词条分布`
- 必要说明：`录入第一条副词条即可开始。`
- 主操作：`去工作台录入`

## 模型评估

- 价值句：`积累历史后自动开启模型评估`
- 必要说明：`先建立 20 条上下文，再积累 20 条有效回测。`
- 主操作：`去工作台录入`

## 状态与边界

- loading 继续使用 `InsightRequestState`，error 继续提供重试动作；二者不复用零样本正文。
- 后端 readiness、样本阈值、共享成熟度和有数据后的模块保持不变。
- 零样本仍通过现有 `start-recording` 事件返回工作台，不新增路由、API 或状态管理。
- 窄屏保持单列和全宽主按钮；暗色模式只做等价表面与文字映射。

## 验收标准

- 两页零样本正文各只有一个 `h3`、一个说明段落和一个主按钮。
- 源码与可访问文本中不存在零样本里程碑、步骤、规则基线来源或按钮后的补充说明。
- 统计、评估有数据状态、loading、error 和现有成熟度状态不受影响。
- 相关 Node 测试、完整前端测试和 Vite 构建通过，并完成浅色桌面与窄屏浏览器检查。
