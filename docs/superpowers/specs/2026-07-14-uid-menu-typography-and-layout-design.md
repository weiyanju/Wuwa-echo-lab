# UID 菜单数据排版与布局节奏设计

## 背景

UID 菜单当前把同一种账号数据处理成了两套视觉角色：已选账号行使用 13px 产品字体和 38px 行高，而新增 UID 输入使用 15px 数据字体和 42px 高度。两者并列后，输入值显得偏大、账号值显得偏弱，确认按钮与输入框也没有落在长期规范要求的 44px 控件基线上。当前账号选中态还使用横向渐变，增加了不必要的装饰噪音。

用户已确认本轮继续优化账号行、新增 UID 字段、确认按钮和区域节奏；当时“退出登录”保持分隔线纯文字样式。

> **后续决策（2026-07-14）：** 用户随后明确将“退出登录”改回轻量菜单行。本文件中保护分隔线纯文字样式的条款仅记录当时的实施边界，已被 `UID 菜单操作层级设计` 和 `DESIGN.md` 的当前规则覆盖。

## 已确认方向

- 已选账号 UID 与输入中的 UID 属于同一种数据内容，统一使用 `--font-data`、`--text-data-sm`、`--weight-data`、`--tracking-data` 和 `tabular-nums`。
- UID 位于可交互控件内，行高统一使用 `--leading-control`，由 44px 控件高度承担垂直居中。
- “新增 UID”属于字段标签，使用 `--text-label`、`--weight-label` 和 `--leading-label`，不再使用 12px caption。
- “确认添加”继续使用已确认的单色泰缇斯蓝主按钮，文字保持 `--text-control` / `--weight-control`。
- 账号行、输入框、确认按钮以及未展开的“添加 UID”入口统一为至少 44px 高、12px 圆角；输入与账号行使用 12px 水平内边距。
- 当前账号选中态改为均匀浅蓝底色，不使用渐变；蓝色边框与右侧勾选图标共同表达 selected，避免只依赖颜色。

## 排版与间距

- 菜单外层继续使用 12px section gap，不改变菜单宽度、定位、圆角或阴影。
- 账号列表行间距由 7px 收敛为 8px。
- 账号列表到“新增 UID”标签的视觉间距为 14px：沿用外层 12px gap，并给表单增加 2px 上边距。
- 标签到输入框使用 8px；输入框到确认按钮使用 10px，由表单 8px gap 与确认按钮 2px 上边距组成。
- 校验错误出现时，错误信息继续紧贴输入框；确认按钮在错误信息之后仍保留 10px 间距。
- 不改变菜单内容的左右边界，账号行、输入框、确认按钮继续同宽对齐。

## 状态与可访问性

- 输入框 focus-visible 使用项目既有的 3px 蓝色轮廓和 3px offset，同时强化蓝色边框；局部规则覆盖当前全局 `input:focus` 对轮廓的覆盖，不修改全站输入框行为。
- hover 只改变颜色、边框或背景，不增加位移、缩放、渐变或投影。
- disabled、busy、校验、提交、账号切换、菜单关闭与焦点恢复逻辑不变。
- 当前账号继续保留勾选图标；不新增装饰图标或额外说明文字。
- 9 位 UID 规则不变；现有 6 位测试 UID 只作为历史测试数据，不影响视觉实现或验收。

## 明确不改

- 不修改 `UidSwitcher.vue` 的模板结构、事件或业务状态。
- 不修改菜单的 320px 宽度、弹出位置、顶部“账号 / 数量”信息或暗色主题结构。
- 不修改已经确认的“退出登录”样式：分隔线、透明背景、无圆角、14px / 600 左对齐文字，以及仅在 hover / focus-visible 时提高危险文字色。
- 不引入新字体、图标、渐变、阴影或页面级视觉 token。

## 验收标准

1. 已选账号值与输入值的计算样式均为数据字体、15px、600、等宽数字，视觉大小一致。
2. 账号行、输入框、确认按钮和“添加 UID”入口的最小高度均为 44px。
3. “新增 UID”为 13px / 600，确认按钮为 14px / 600，三类文字角色清楚但不过度跳级。
4. 浅色与暗色当前账号均为纯色选中面，不含 `linear-gradient`。
5. 键盘聚焦输入框时可见 3px 蓝色轮廓，鼠标 hover 不产生布局移动。
6. 默认、新增、校验错误、暗色和 320px 级窄屏状态均无溢出或边缘错位。
7. “退出登录”与当前已确认版本视觉一致，现有回归断言保持通过。
