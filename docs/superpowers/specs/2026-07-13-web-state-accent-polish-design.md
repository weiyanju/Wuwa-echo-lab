# Web 状态强调视觉优化设计

## 背景

当前 Web 界面在登录标题、套装选择、预测行、历史筛选、历史记录和模型判断中，多次使用超过 1px 的彩色左侧条表达状态。这些实现既违背 `DESIGN.md` 与 impeccable 的界面约束，也让相互独立的状态看起来像同一种告警或引用块。

本次优化以审美和信息表达为第一目标。禁止侧边条是约束，不是设计结果；最终结果必须通过更完整的层级、边界、图标与文字语义提升可读性。

## 设计原则

1. 状态不只依赖颜色：选中态配合勾选图标或现有状态文字，预测态保留上升图标。
2. 强调围绕整个对象：使用 1px 完整边框、均匀低饱和底色和必要的紧凑焦点环，不在单侧集中视觉重量。
3. 不制造悬浮卡片噪声：筛选项和记录项取消抬升与宽阴影，交互反馈以边框、底色和清晰焦点态为主。
4. 复用现有系统：继续使用项目 token、IBM Plex 字体角色、Iconoir 风格图标和现有圆角尺度，不引入新视觉体系。
5. 浅色、深色、响应式与键盘状态同时成立。
6. 先判断线条是否承载数据或结构语义：卡片装饰侧条必须移除；进度条、坐标轴、输入光标和明确编码路径类型的图形可以保留。

## 场景设计

### 登录标题

移除标题左侧蓝条和与之绑定的左内边距，利用标题本身的字号、终端打字光标和更紧凑的垂直留白建立焦点。移动端同步取消侧边条，避免窄屏出现多余的装饰轴线。

### 套装选择

选中项使用完整主色边框、均匀浅色底和右侧勾选标记。布局从“图标 + 文本”扩展为“图标 + 文本 + 状态标记”，让选中态在灰度和低色觉条件下仍然明确。悬停只改变边界与底色，不产生位移。

### 最高预测行

移除所有行预留的透明侧条及最高预测行的彩色内嵌条。最高预测行保留绿色完整边框、均匀的低饱和背景和既有上升图标；因此语义仍清晰，但不会与引用块或告警条混淆。

### 历史筛选与记录

筛选项采用紧凑分段筛选语言：激活项显示勾选标记、完整语义边框和均匀底色，取消抬升、宽阴影和单侧条。记录项使用 1px 完整状态边框、均匀背景和现有“当前 / 待强化 / 已强化 / 弃置”徽标；当前项增加克制的完整焦点环，不改变卡片尺寸。

### 模型判断摘要

将引用式左边条改为紧凑的两列信息行：固定的“判断”标签负责建立阅读入口，正文负责解释模型结论。容器使用低对比完整边界和轻底色，与图表内容保持从属关系，不再伪装成引用块。

## 二次全站复核与纠正

首轮实现只搜索了显式 `border-left` 和水平 inset 阴影，未覆盖伪元素以及顶部边缘强调，因此不能据此宣称全站问题已经解决。二次复核同时检查：

- `border-left`、`border-right` 与逻辑方向边框。
- 水平 inset 阴影形成的侧条。
- 卡片、列表项和提示中的绝对定位伪元素。
- 圆角卡片上超过 1px 的彩色顶部边框和顶部 inset 阴影。
- 浅色、暗色和响应式分支。

### 必须纠正的遗漏侧条

`model-detail-thumb::before` 是模型详情选择项左侧的 3px 渐变状态条。它没有独立数据含义，应移除伪元素及其 active/transition 规则；选择状态继续由完整边框、背景和既有文字表达。

### Bayes 路径标记保留

`bayes-path-list article::before` 保留。它位于卡片内部而非边缘，并通过绿色实线与紫色虚线分别编码 Exact 主路径和 Wildcard 泛化路径。该线条被定义为路径图形的一部分，不作为卡片装饰边框；测试只对这一明确选择器豁免，不能扩展为其他卡片侧条的通用许可。

### 评估页顶部强调收敛

以下顶部粗线不承载新的数值或结构信息，并与已有完整边框、背景、标签、数值或进度条重复，因此统一移除：

- `cycle-window-grid article` 的 3px 顶边。
- `model-group-bars div` 的 2px 顶边。
- `model-bars-large div` 的 3px 顶边。
- `markov-penalty-grid article` 的 3px 顶边。
- `model-bars article.expanded`、`best` 与 `best.expanded` 的 3px inset 顶线。

这些对象保留 1px 完整边框和现有低饱和表面；最高命中、窗口类型、权重和惩罚信息继续由文字、数值、标签与数据条承担。进度条、Markov 箭头、图表基准线、时间轴刻度、标题下划线和登录打字光标不属于本次移除范围。

### 测试守卫

全站状态强调测试必须覆盖全部 Web 样式 owner，不能只列举首轮修改过的四个 feature 文件。测试需要：

- 拒绝卡片、列表项、提示和状态中的超过 1px 彩色左右边框或等效水平 inset 侧条。
- 明确断言遗留的 `model-detail-thumb` 侧条已经删除。
- 明确断言上述评估卡片不再使用超过 1px 的顶部强调。
- 保留并说明登录光标、图表箭头、轴线以及 Bayes 路径标记等功能性豁免。
- 避免把测试文件中的正则文本误判为产品 CSS。

本次纠正只改变视觉样式和设计守卫，不改变 Vue 业务流程、API 契约、数据结构或信息架构。

## 无障碍与交互

- 保留 `aria-current` 与 `aria-pressed`。
- 新增的勾选图标为装饰性图标，使用 `aria-hidden="true"`；状态仍由原生 ARIA 属性表达。
- 所有按钮保留现有键盘焦点样式，不通过颜色单独传达状态。
- 不新增持续动画；现有状态过渡限制在颜色、边框和不影响布局的属性。
- `prefers-reduced-motion` 规则继续生效。

## 验收标准

- 除明确记录的功能性图形外，目标选择器不再包含超过 1px 的彩色左右侧边条或等效 inset 阴影。
- `model-detail-thumb` 遗留侧条删除，Bayes 路径实线/虚线标记保留。
- 评估页五组冗余顶部粗线全部移除，完整 1px 边框、背景、标签和数据图形仍能清楚表达状态。
- 登录页打字光标、图表轴线、Markov 箭头和时间轴刻度等功能性边线保留。
- 套装与历史筛选选中态具有非颜色视觉标记。
- 浅色、深色、桌面与窄屏下均无布局跳动或文本遮挡。
- 前端针对性测试、全量测试、生产构建和 `git diff --check` 通过，并完成真实浏览器视觉检查。
