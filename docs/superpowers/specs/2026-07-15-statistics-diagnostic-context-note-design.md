# 统计诊断上下文说明设计

## 背景

“样本仍少，偏差只作早期提示。”目前位于“样本可信度”单元内部。它实际约束的是整个统计诊断区域，尤其是“当前偏高 / 当前偏低”的精确百分比，而不是只解释可信度阶段。放在首个单元内会让第一列比另外两列更拥挤，也会造成说明范围与视觉归属不一致。

## 设计决策

- 删除说明文字在 `.stats-diagnostic-primary` 内的位置。
- 在“统计诊断”标题下显示一行区域级上下文说明，与右侧阶段标签共同构成诊断标题区。
- 说明保留可见，不改为 tooltip、图标或隐藏帮助，因为用户需要在阅读精确偏差前看到样本量约束。
- 不改变“起步观察”的阶段名称和现有绿色阶段色；本次不是彻底删除风险说明，因此无需改写阶段颜色语义。

## 文案体系

说明统一包含实际样本数，并继续随可信度阶段变化：

- `< 500`：`基于 {total} 条样本，当前偏差仅作趋势提示。`
- `500–2999`：`基于 {total} 条样本，偏差可作初步参考。`
- `3000–9999`：`基于 {total} 条样本，偏差可辅助判断，极端值仍需保守看待。`
- `10000–49999`：`基于 {total} 条样本，偏差趋势可作为长期观察依据。`
- `≥ 50000`：`基于 {total} 条样本，可进入长期权重优化。`

文案不重复“起步观察”，也不使用“早期提示”这种缺少具体阅读动作的表达。

## 布局与排版

- 说明位于 `.stats-diagnostic-title-stack` 内、标题正下方。
- 标题区使用顶部对齐，阶段标签与标题首行对齐，不与两行标题栈垂直居中。
- 标题与说明间距为 6px。
- 说明最大宽度 440px；字号使用 Label（13px），字重 500，行高使用正文行高。
- 浅色主题使用中性蓝灰 `#6f8293`；暗色主题沿用现有次级文字色。
- 不添加边框、底色、图标、胶囊或额外提示行。
- 诊断三列内，“样本可信度”只保留标签和阶段值，使三列纵向密度更接近。

## 无数据状态

- 无正向偏差时只显示“暂无明显偏高”，不再同时渲染第二个“暂无”百分比占位。
- 无负向偏差时只显示“暂无明显偏低”，不再同时渲染第二个“暂无”百分比占位。
- 有偏差数据时，名称与百分比布局保持现状。

## 响应式与可访问性

- 桌面端说明与标题左对齐，阶段标签继续位于右侧。
- 860px 以下沿用现有标题区纵向堆叠；说明跟随标题，阶段标签排在其后。
- 说明保持真实文本节点，不依赖 `title` 属性传达关键信息。
- 现有诊断区域 `aria-label`、偏差项 `title` 和数据语义保持不变。

## 非目标

- 不改变阶段阈值、阶段名称、偏差算法或排序。
- 不重设计阶段标签、图表卡片或统计页面整体颜色体系。
- 不新增图标、tooltip 或弹层。

## 验证范围

- 0、130、500、3000、10000 和 50000 条样本的动态说明。
- 标题下说明位置、首列旧说明移除和浅色/暗色排版。
- 偏高或偏低为空时不重复显示“暂无”。
- 860px 以下标题、说明和阶段标签的堆叠。
- 统计聚焦测试、架构测试、完整前端测试、Vite 构建与 `git diff --check`。
