# UID 菜单非等权同行操作设计

## 背景

UID 菜单此前将“退出登录”放在独立页脚行。用户进一步明确：默认状态下“添加 UID”和“退出登录”应位于同一行，但不能等分，也不能拥有相同视觉权重。新增入口是常规账号管理动作，退出登录是低频账号命令。

本规格取代此前“独立退出页脚”的当前实现方向；既有实施记录继续作为历史决策保留。

## 信息层级

菜单按以下顺序组织：

1. 账号标题与容量 `1 / 5`。
2. 当前账号及其他可切换账号。
3. 非等权同行操作区。

默认操作区左侧为“添加 UID”，右侧为“退出登录”；进入新增状态后，左侧切换为“确认添加”，右侧切换为“取消”。新增状态不继续显示退出登录，避免低频账号命令与当前提交任务并列。

## 布局规格

- 菜单宽度保持 320px，窄屏最大宽度为 `calc(100vw - 32px)`。
- 菜单锚定 `UidSwitcher` 自身，右边缘与 UID 胶囊右边缘对齐。
- 菜单圆角使用 16px，内边距使用 16px，内容纵向间距使用 12px。
- 操作区使用两列 Grid：`minmax(0, 1fr) 88px`，列间距 8px。
- 左右操作均为 44px 高；相同高度只表达稳定点击面积，不表达相同权重。
- 默认状态不再绘制退出登录独立行、页脚分隔线或额外底部留白。
- 窄屏保持同行结构，不改为 50/50，也不堆叠；中文短标签在最小菜单宽度下仍可完整显示。

## 排版规格

- 菜单标题“账号”使用 Label：13px / 600。
- 容量 `1 / 5` 使用数据字体、13px / 600、等宽数字。
- UID 数据继续使用 Data SM：15px / 600、等宽数字。
- “添加 UID”和“确认添加”使用 Control：14px / 600。
- “退出登录”和“取消”使用 Label：13px / 500。
- 所有按钮文字在各自点击区域内水平和垂直居中，不添加图标。

## 颜色与层级

### 浅色主题

- “添加 UID”：`#1769d2` 文字、`rgba(23, 105, 210, 0.24)` 实线边框、`rgba(23, 105, 210, 0.06)` 背景。
- “添加 UID” hover：边框提升至 `rgba(23, 105, 210, 0.44)`，背景提升至 `rgba(23, 105, 210, 0.10)`。
- “确认添加”：系统主蓝实底、冷白文字、无渐变、无装饰性投影。
- “退出登录”：默认使用 `#6f8293` 中性文字、透明背景、无可见边框；hover / focus-visible 使用系统危险文字和 `rgba(228, 30, 63, 0.07)` 弱危险背景。
- “取消”：默认与退出命令共用 `#6f8293` 中性文字和透明背景；hover / focus-visible 使用更深中性文字与 `rgba(82, 102, 117, 0.08)` 中性背景，不进入危险态。

### 暗色主题

- “添加 UID”：`#9acbff` 文字、`rgba(93, 168, 255, 0.32)` 边框、`rgba(93, 168, 255, 0.08)` 背景。
- “退出登录”：默认使用 `#aebdca`，hover / focus-visible 使用 `#ffd4db` 与 `rgba(255, 105, 128, 0.12)`。
- “取消”：默认与退出命令共用 `#aebdca` 暗色主题中性文字，hover / focus-visible 使用弱白背景，不使用危险色。

## 菜单表面

- 菜单使用单一实色表面，不使用装饰性渐变。
- 浅色主题保留 1px 冷灰边框，阴影收敛为 `0 8px 12px rgba(39, 55, 71, 0.10)`。
- 暗色主题使用现有 `--surface-soft` 表面和相同深度关系，不使用大面积雾化阴影。

## 交互状态

- 点击“添加 UID”后显示全宽标签、输入框和错误信息，焦点进入 UID 输入框。
- 新增状态下左侧操作为“确认添加”，通过 `form` 属性提交原有表单；右侧操作为“取消”。
- 点击“取消”调用现有表单重置逻辑，恢复默认操作区，并把焦点返回“添加 UID”。
- 达到 5 个账号时，左侧显示“已达上限”并禁用；右侧“退出登录”保持可用。
- busy 状态沿用现有菜单关闭逻辑，不新增加载布局。
- Escape、点击菜单外部、账号切换和退出事件保持现有行为。
- focus-visible 始终使用系统蓝色清晰轮廓，不能只依赖颜色变化表达焦点。

## 可访问性

- 操作区容器使用 `role="none"`，不引入额外语义层级。
- “退出登录”保持 `role="menuitem"` 和原有可访问名称。
- “取消”使用普通 `type="button"`，避免触发表单提交。
- 所有操作保留至少 44px 点击高度。
- 键盘顺序为账号列表、左侧主要操作、右侧上下文操作。

## 验证范围

- 默认状态：添加与退出同排、非等宽、无独立退出行。
- 新增状态：全宽输入区域，下方为“确认添加 / 取消”同行操作。
- 达到上限、busy、校验错误、浅色、暗色和窄屏状态。
- 菜单锚点、焦点进入、取消后的焦点恢复、Escape 与点击外部关闭。
- UID 组件测试、架构测试、完整前端测试、Vite 生产构建和 `git diff --check`。
