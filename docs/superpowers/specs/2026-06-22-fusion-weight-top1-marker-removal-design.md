# 融合权重 Top1 标记移除设计

## 目标

让“当前融合权重”区域只表达模型权重，避免把 Top1 回测命中率与权重叠加在同一刻度上造成误读。

## 调整范围

- 从融合权重图例移除“Top1 命中率”。
- 从每张融合权重卡片移除 Top1 三角标记。
- 从权重卡片 tooltip 和无障碍说明中移除 Top1 回测文案。
- 删除只服务于上述图例和三角标记的 CSS。

## 保留范围

- 保留当前权重、基础权重及权重调整方向。
- 保留下方核心回测中的 Top1、Top3、Top5 指标。
- 保留模型详情中的独立命中率和权重变化解释。
- 不改变后端评估数据、融合算法或 API 契约。

## 验收

- “当前融合权重”区域源码不再包含 Top1 命中率图例、标记或 tooltip。
- 核心回测仍展示 Top1、Top3、Top5 命中率。
- 前端全量测试与生产构建通过。
