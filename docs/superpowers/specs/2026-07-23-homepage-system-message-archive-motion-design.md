# 首页系统消息“状态归档”动效设计

**日期：** 2026-07-23<br>
**状态：** 用户已确认视觉方向，待书面规格审阅<br>
**适用范围：** `WuwaFrontend` 首页标题“欢迎回家，漂泊者”及认证卡片入场衔接

## 1. 决策摘要

首页继续逐字输出“欢迎回家，漂泊者”。逐字输入是泰缇斯系统向用户返回信息的核心叙事，不删除、不改成整段淡入，也不增加删除重打、循环播放或音效。

本次采用用户确认的“状态归档”方案：输出期间，蓝色竖条表示系统仍在生成消息；中文逗号出现时竖条短暂收缩，表达语义停顿；末字完成后，竖条压缩为短点，认证卡片几乎同时接过注意力；短点随后淡出，页面进入完全静止状态。

光标不再无限闪烁。标题不可编辑，无限闪烁会把它误读为编辑器插入点，也让首页长期停留在“演示中”。新的竖条拥有明确的出现、工作、归档和退出阶段。

本设计修订并覆盖以下旧规则中与光标收尾直接冲突的部分：

- [`2026-07-13-login-title-caret-spacing-design.md`](./2026-07-13-login-title-caret-spacing-design.md) 中“保留 4px 光标和闪烁节奏”的决定。
- [`2026-07-14-homepage-typewriter-animation-design.md`](./2026-07-14-homepage-typewriter-animation-design.md) 中“标题完成后保留光标闪烁”和“光标最终停在标题末端”的决定。

旧设计中的完整 Unicode 字素推进、字体切片预载、180ms 字体准备上限、只播放一次、认证入口不可提前交互、后台静态完成、窄屏静态完成和减少动态效果降级继续有效。

## 2. 目标与非目标

### 目标

- 保留“系统正在逐字输出”的产品叙事，同时去除黑客马拉松或代码编辑器联想。
- 让竖条准确表达输出状态，而不是永久装饰。
- 通过标点停顿、末字归档和认证卡片接棒建立一条连贯的注意力路径。
- 保持首页浅色终端风、Tethys 蓝、IBM Plex 字体角色和现有布局。
- 不因动效延长认证入口的实际等待时间或改变认证数据流。

### 非目标

- 不修改标题、协议标签、能力列表或认证表单文案。
- 不重排首页宏观布局，不改变登录卡片尺寸、字段或认证模式。
- 不把标题动效抽象成全站通用动画框架。
- 不增加音效、粒子、扫描线、发光、字符乱码、删除重打或循环重播。
- 不修改登录、注册、账号保存、UID 绑定或工作台业务逻辑。

## 3. 视觉语言

### 逐字内容

- 标题继续使用 IBM Plex Sans SC 的既有 Display 角色、字号、字重和 Tethys 文本色。
- 每一帧只能显示完整 Unicode 字素前缀；不得使用宽度、裁切或遮罩模拟打字。
- 已出现的文字保持静止，不做逐字上浮、缩放、发光或透明度回弹。

### 系统输出指示器

- 竖条宽度由现有 `4px` 调整为 `2px`，高度约为当前标题字高的 `0.9em`。
- 与末字继续保留既有 `0.14em` 视觉间距，避免粘连。
- 颜色使用现有 Tethys 主蓝，不引入新强调色、渐变或阴影。
- 输出期间竖条稳定显示，不闪烁。
- 逗号出现后，竖条在约 `170ms` 内收缩到正常高度的约 `68%`、透明度约 `45%`，随后恢复，形成可感知但不抢眼的语义停顿。
- 末字完成后进入归档：竖条在约 `220ms` 内压缩为约 `4–5px` 的短点。
- 短点停留后淡出；完成态不保留光标、短点或任何无限动画。

### 认证卡片接棒

- 认证卡片继续只使用 `opacity` 和轻微 `translateY` 入场。
- 归档开始约 `40ms` 后，认证卡片开始进入；它不等待短点完全淡出。
- 入场时长约 `260ms`，使用现有快速指数 ease-out。
- 卡片开始进入时即可按现有门控策略进入可访问树和交互流程；视觉过渡不得重置表单状态。

## 4. 状态机与时序

动画由显式状态驱动，不再只用“标题是否完成”一个布尔值承载所有阶段。

| 阶段 | 标题 | 指示器 | 认证卡片 |
| --- | --- | --- | --- |
| `preparing` | 等待最终字体字形 | 不显示或保持初始静止态 | 不可见、不可交互 |
| `typing` | 逐个追加完整字素 | 2px 蓝色竖条，稳定跟随末字 | 不可见、不可交互 |
| `punctuation` | 逗号已完整显示 | 短暂收缩后恢复 | 不可见、不可交互 |
| `resolving` | 完整标题静止 | 竖条压缩为短点 | 40ms 后开始进入 |
| `completed` | 完整标题静止 | 淡出并移除视觉占位 | 完全可见、可交互 |
| `static` | 立即显示完整标题 | 不显示 | 立即可见、可交互 |

正常桌面时序使用已确认的确定性语义节奏：

- 字体准备成功后，保留 `180ms` 的系统准备停顿，再输出首字。
- 七个字素间隔依次为 `90 / 64 / 98 / 70 / 250 / 94 / 72ms`；其中 `250ms` 是逗号后的语义停顿。
- 末字出现后保留 `166ms`，再进入 `resolving`。
- `resolving` 开始约 `40ms` 后让认证卡片接棒。
- 短点在 `resolving` 开始约 `420ms` 后进入淡出，淡出约 `220ms`。
- 用户在输出开始后约 `1.12s` 看到认证卡片开始进入；短点退出不阻塞认证交互。

动画只自动播放一次。登录/注册切换、字段输入、校验错误、提交失败、UID 绑定返回或认证卡片内部页面切换均不得重播标题。

## 5. 组件边界与数据流

继续沿用现有 owner，不加厚 `App.vue`：

- `titleAnimation.js` 负责确定性字素序列、阶段时序和计时器清理，不访问认证业务。
- `useTitleAnimation.js` 负责字体准备、媒体条件、页面可见性、生命周期取消和静态降级。
- `LoginView.vue` 只消费可见标题、动画阶段、指示器阶段和认证就绪状态，渲染标题与认证卡片。
- `auth.css` 使用现有 token 表达竖条、短点、淡出和认证卡片接棒，不创建单页视觉体系。

组合函数向视图提供等价于以下语义的数据，不要求实现拘泥于具体字段名：

- 当前完整字素前缀。
- `preparing / typing / punctuation / resolving / completed / static` 阶段。
- `bar / compressed / dot / hidden` 指示器状态。
- 认证卡片是否就绪。

“完整标题”“认证就绪”和“归档动画结束”是三个不同事件。认证卡片可在短点退出前接棒，不能再由一个 `titleComplete` 布尔值同时代表三者。

## 6. 静态降级、失败处理与可访问性

- `prefers-reduced-motion: reduce` 下直接进入 `static`：完整标题和认证卡片立即可用，不逐字推进，不显示竖条或短点。
- `520px` 及以下继续直接进入 `static`，保持现有自然换行，不在窄屏播放标题动画。
- 页面在准备或播放期间进入后台时立即静态完成；返回页面后不补播。
- Font Loading API 不可用、字体准备为空、异常或超过 `180ms` 时静态完成，不因品牌动效阻塞登录。
- 组件卸载时清理所有计时器、监听和迟到异步结果。
- `h1` 始终提供稳定的完整无障碍名称“欢迎回家，漂泊者”；可见逐字节点和指示器不得触发屏幕阅读器逐字播报。
- 指示器保持 `aria-hidden`，不使用 caret 或 textbox 语义。
- 认证卡片在就绪前不进入键盘焦点顺序、指针命中范围或无障碍树；就绪后立即恢复现有交互语义。

## 8. 测试与验收

### 确定性测试

- 每一帧都是完整标题的合法 Unicode 字素前缀。
- 验证普通间隔、逗号停顿、末字停留、归档、认证接棒和短点退出的顺序。
- `typing` 期间指示器稳定，无无限 blink 定时器或 CSS 循环动画。
- 逗号时进入 `punctuation`，随后回到 `typing`。
- 完整标题后进入 `resolving`；认证先就绪，指示器随后隐藏；最终进入 `completed`。
- 取消、卸载和页面隐藏后，不再有迟到状态更新。

### 组件与样式测试

- 指示器是独立、`aria-hidden` 的渲染节点，不重新使用标题 `border-right`。
- 宽度为 `2px`，使用现有蓝色 token 和 `0.14em` 间距。
- 所有空间动效只修改 `transform` 和 `opacity`。
- 认证卡片在接棒前不可聚焦、不可点击且不进入无障碍树，接棒后立即恢复。
- reduced-motion、`520px` 以下、后台和字体失败路径均直接显示完整标题与认证卡片，且不显示指示器。
- 登录、注册、校验、账号保存和提交事件保持现有契约。

### 浏览器与视觉验收

- 桌面正常、冷缓存、字体加载失败和页面中途隐藏场景均无半字、字体替换闪烁或布局跳动。
- 输出期间竖条不闪烁；逗号收缩可感知但不夺目；末字后压成短点并完全退出。
- 认证卡片在短点退出前自然接棒，用户不感到额外空拍。
- 完成后页面完全静止，不再像编辑器或黑客终端。
- 在 `320 / 375 / 414 / 768px` 和桌面视口验证换行、无横向溢出、焦点顺序和静态降级。
- 运行前端定向测试、全量测试、生产构建和 `git diff --check`。

## 9. Hallmark 自检

- **Philosophy 5：** 动效表达系统输出与归档，不是无语义装饰。
- **Hierarchy 5：** 标题完成后由认证卡片接管注意力，光标不长期争夺焦点。
- **Execution 5：** 状态、计时、降级、取消和可访问性契约完整。
- **Specificity 5：** 复用 Tethys 蓝、IBM Plex 字体、完整字素和首页既有结构。
- **Restraint 5：** 不增加新容器、颜色、发光、粒子、音效或循环动画。
- **Variety 4：** 用“竖条归档为短点”形成页面专属完成语义，同时保持克制。
