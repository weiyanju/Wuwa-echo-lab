# 登录框 UID 绑定页底部“返回登录”设计修订

**日期：** 2026-07-19<br>
**状态：** 用户已确认视觉方向，待实施计划<br>
**适用范围：** `WuwaFrontend` 登录框内部的首次 UID 绑定页

## 1. 决策摘要

首次 UID 绑定页不再在标题左侧显示返回图标。标题、说明、字段标签、输入框和提示信息恢复为同一条左基线。

“退出当前系统账号并回到登录页”改为登录框底部的灰色文字按钮“返回登录”，放在蓝色主按钮 `BIND_AND_ENTER()` 下方。该按钮属于低频次级操作，不再伪装成页面层级导航。

本修订只覆盖 [`2026-07-19-login-card-uid-onboarding-design.md`](./2026-07-19-login-card-uid-onboarding-design.md) 中关于返回图标位置、造型和验收标准的内容。登录框内页面切换、退出行为、UID 校验、外层登录页冻结和后续账号菜单职责保持不变。

## 2. 设计依据

标题区返回图标存在两个无法同时满足的问题：

- 保留 `44 × 44px` 点击目标时，图标会迫使标题产生额外缩进，破坏标题与字段的左对齐。
- 将图标移入卡片边距或标题角落时，容易被理解为页面导航，但其真实行为是退出当前账号。

底部文字动作更符合行为权重：

- 蓝色只保留给“绑定并进入”这一唯一主操作。
- “返回登录”明确表达结果，并通过灰色文字降低权重。
- 标题区不再承担退出动作，卡片内容可以使用统一左基线。
- 不需要新图标、额外边框、分隔线或第二个实体按钮。

## 3. 结构

```text
┌────────────────────────────────────┐
│ 绑定游戏 UID                       │
│ 首次进入需要绑定一个游戏账号。     │
│                                    │
│ > 游戏 UID                         │
│ [ 输入你的 UID                   ] │
│ 可在游戏个人信息页查看 UID         │
│                                    │
│ [       BIND_AND_ENTER()         ] │
│              返回登录              │
└────────────────────────────────────┘
```

规则：

- 标题、说明、字段标签、输入框和提示信息共用登录框内容左基线。
- 主按钮继续使用现有蓝色实底、全宽和命令式文案。
- “返回登录”位于主按钮下方，水平居中。
- 两个动作之间保留紧凑间距，不增加分隔线。
- “返回登录”保留至少 `44px` 点击高度，但点击宽度只覆盖文字及必要水平内边距，不扩展为第二个全宽按钮。

## 4. 视觉状态

### 默认

- 可见文案：`返回登录`。
- 使用登录入口现有中性次级文字色。
- 无图标、无边框、无底色、无阴影。
- 使用产品 Sans 的 Control 字体角色，不使用 Mono。

### Hover

- 仅将文字加深到主要文本色。
- 不出现蓝色底、灰色实体底、边框、下划线、位移或缩放。

### Focus visible

- 保留灰色或主要文本色文字。
- 使用现有 Tethys 蓝焦点轮廓和明确的轮廓偏移。
- 焦点轮廓只包围文字按钮的实际点击区域。

### Active

- 不产生位移、缩放或弹跳。
- 可以沿用 hover 的主要文本色。

### Disabled / busy

- UID 绑定请求、账号切换或退出请求进行中时禁用。
- 保留文案，通过透明度和禁止光标表达不可用。
- 不改变尺寸，不替换为加载图标。

错误和绑定成功状态不改变“返回登录”的视觉语义；错误继续归属 UID 字段，绑定成功直接进入工作台。

## 5. 行为与可访问性

- 控件继续使用原生 `<button type="button">`。
- 点击后继续发出既有 `cancel` 事件，由上层执行退出当前账号并返回认证页。
- 可见文案使用规范写法“返回登录”。
- `aria-label` 和 `title` 使用完整语义“退出当前账号并返回登录”。
- busy 时与 UID 输入和主按钮同时禁用，避免绑定与退出竞态。
- 键盘顺序为 UID 输入、绑定主按钮、返回登录按钮。

## 6. 动效

“返回登录”本身只允许颜色状态变化，时长沿用登录入口现有 `80–120ms` 控件反馈。

点击后的认证页反向切换继续使用已有登录框内部页面过渡：

- 只动画 `opacity` 与 `transform`。
- 外层登录页、登录框边界和尺寸不移动。
- `prefers-reduced-motion: reduce` 下取消空间位移。

## 8. 测试与验收

- 组件测试先证明旧的图标结构不满足新契约，再实施生产修改。
- 组件结构中不再存在返回 SVG 或标题左侧图标按钮。
- 可见“返回登录”按钮继续触发 `cancel`。
- 返回按钮与 UID 输入、主按钮在 busy 时同时禁用。
- 样式测试覆盖居中、灰色文字、至少 `44px` 点击高度、无默认边框和无默认底色。
- 覆盖 hover、focus-visible、active、disabled 和 reduced-motion。
- 完整前端测试和生产构建通过。
- 使用无 UID 测试账号人工确认：
  - 登录后只切换登录框内部内容。
  - 标题与表单左对齐。
  - “返回登录”位于主按钮下方且不与主按钮争夺视觉权重。
  - 点击后退出当前账号并返回登录表单。

## 9. Hallmark 组件自检

- **Philosophy 5：** 次级操作权重与真实行为一致。
- **Hierarchy 5：** 蓝色只属于绑定主操作，返回登录降为灰色文字动作。
- **Execution 5：** 原生按钮、44px 点击高度、焦点和禁用状态完整。
- **Specificity 5：** 使用现有 Tethys token、字体和登录入口结构。
- **Restraint 5：** 不新增图标、容器、分隔线、阴影或动画。
- **Variety 4：** 采用表单底部次级动作，而不是重复工具栏式返回图标。
