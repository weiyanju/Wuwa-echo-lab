# 评估子模型判断摘要同源表面设计

> 已被 `2026-07-19-evaluation-model-judgement-visible-parent-surface-design.md` 取代。原方案把表面色 owner 放在生产页面中背景透明的内层模型卡片，无法保证判断摘要跟随用户实际看到的外层回测卡片；本文件仅保留为历史决策记录。

## 背景

模型评估页的每张子模型详情都包含同语义的“判断”摘要。该摘要位于具体子模型卡片内部，因此它不应脱离父卡片变成全局统一的中性窗口，也不应维护一套与卡片背景无关的独立颜色表。

当前实现存在两个颜色来源：

- 子模型卡片背景通过各模型选择器分别声明蓝、紫、琥珀、绿或灰色轻渐变。
- 判断摘要的背景、边框和标签从 `--model-accent` 派生。

两套来源并不总是一致。例如 Bayes 卡片背景偏紫，但判断摘要会继承默认绿色；Markov 卡片与摘要都偏琥珀，但摘要边框和标签使用的色彩强度较高，容易接近警告框。

正确方向不是让所有判断摘要显示同一种颜色，而是让它们遵循同一套派生规则：色相来自所属卡片，层级和强度保持一致。

## 目标

- 每个子模型卡片只维护一个表面身份色来源。
- 卡片背景与内部判断摘要从同一表面身份色派生。
- 不同子模型判断摘要保持各自色相，但拥有一致的视觉层级。
- 判断摘要比当前更克制，仍然像卡片内部的说明层，而不是警告或独立状态框。
- 保留现有模型数据图形和状态标签的颜色语义。
- 保持布局、圆角、间距、文案、模型逻辑和交互不变。
- 浅色与深色主题使用同一套派生关系。

## 非目标

- 不把所有子模型判断摘要改成相同的中性色。
- 不调整子模型权重、命中率、Loss、排序或状态判断。
- 不修改 Markov、Bayes、规则、窗口或上下文数据图形的颜色映射。
- 不改变判断摘要的 DOM 结构、字号、字重、圆角或内边距。
- 不修改 API、数据库、评估数据结构或滚动锚点行为。
- 不借本次修改重构整个评估页配色。

## 设计决策

### 表面色与数据色分层

在 `.model-insight-card` 上新增卡片局部表面 token：

- `--model-surface-accent`：卡片及内部说明表面的色相来源。
- `--model-card-tint`：父卡片背景渐变的强度。

现有 `--model-accent` 继续服务模型数据图形、进度和其他已经批准的视觉表达，不因为本次表面整理而改变。表面色和数据色允许在同一色系内使用不同明度或饱和度，避免为了整理 CSS 意外修改图表。

### 卡片表面映射

局部表面 token 以当前浅色卡片背景为基线：

| 卡片 | 表面色 | 卡片渐变强度 |
|---|---|---:|
| 默认 / 规则均衡 | 蓝 `#1769d2` | `7%` |
| Bayes 周期规律 | 紫 `#7156be` | `9%` |
| Markov 近期序列 | 琥珀 `#ffb020` | `11%` |
| 词条窗口 | 绿 `#30a46c` | `10%` |
| 上下文监测 | 继承当前默认蓝色表面 | `7%` |
| 未启用 | 灰 `#677481` | `8%` |

卡片背景改为消费这两个局部 token，最终浅色视觉保持当前基线。深色卡片也从同一个 `--model-surface-accent` 派生，使同一模型在浅色和深色主题下保持同一表面色相。

### 判断摘要表面

`.model-judgement-summary` 从父卡片的 `--model-surface-accent` 派生：

浅色主题：

- 背景：`4%` 表面身份色与现有近白说明表面 `#f7f9fb` 混合。
- 边框：`10%` 表面身份色与现有柔边界 `#d8e2ea` 混合。
- 正文：继续使用当前中性深灰正文色。

深色主题：

- 背景：`6%` 表面身份色与暗色次级表面 `--surface-soft` 混合。
- 边框：`16%` 表面身份色与暗色柔边界 `--hairline-soft` 混合。
- 正文：继续使用当前暗色说明文字色。

不同模型会得到蓝、紫、浅琥珀、绿或灰色判断表面，但配色强度和层级一致。Markov 仍与父卡片保持琥珀关系，色彩面积和边界对比低于当前实现，不把普通说明强化成警告。

判断摘要继续保留：

- 两列网格。
- `10px` 圆角。
- `8px 10px` 内边距。
- 当前字号、字重和行高。

纯颜色调整不得改变详情高度、滚动锚点或响应式布局。

### “判断”标签

`.model-judgement-label` 使用 `46%` 的 `--model-surface-accent` 与主题正文墨色混合：

- 保留所属模型的色相关联。
- 比当前直接使用高比例 `--model-accent` 更克制。
- 正文不跟随模型色，避免整行可读性下降。
- 浅色 Markov 标签与其派生背景的对比度约为 `4.82:1`，其他模型更高，满足普通文字 WCAG AA；深色主题使用相同比例与暗色 `--ink-deep` 混合。

标签继续通过固定文案、600 字重、较小字号和独立列建立阅读入口，不新增色点、图标、侧边条或模型徽标。

### 状态色边界

真实状态继续由现有状态标签表达：

- 主导。
- 参与中。
- 低权重。
- 未启用。

判断摘要不根据权重、命中率、Loss、重复次数或冷却阈值切换颜色。未启用时父卡片本身进入灰色表面，判断摘要随父卡片表面 token 自然转灰。

## 实现边界

修改限定在：

- `WuwaFrontend/src/styles/features/evaluation.css`
- 对应的前端静态设计守卫或评估组件测试
- 本设计成为长期事实后需要同步的视觉规范与实施记录

Vue 模板无需修改。不得新增全局 UI token；表面身份色是评估卡片内部的 feature token。

## 验证

### 自动验证

- 新增失败优先的静态断言，确认卡片背景和判断摘要都消费 `--model-surface-accent`。
- 确认判断摘要不再直接从 `--model-accent` 派生。
- 确认现有模型数据图形仍继续使用 `--model-accent`。
- 确认判断摘要仍保留完整边框、两列布局和现有几何。
- 运行评估组件相关测试。
- 运行前端全量测试和生产构建。
- 运行 `git diff --check`。

### 视觉验证

在已有登录业务数据的评估页核对：

- 浅色主题下分别展开规则、Bayes、Markov、词条窗口和上下文模型。
- 每个判断摘要与所属卡片处于同一色系，且摘要层级强度一致。
- Bayes 判断摘要跟随紫色卡片，不再显示与父卡片无关的绿色表面。
- Markov 判断摘要保留浅琥珀关联，但不呈现为高权重警告框。
- 深色主题下重复同一对比，同一模型保持相同色相关系。
- Markov 时间带、Bayes 路径、规则偏差和周期窗口等数据图形颜色保持不变。
- 主导、参与中、低权重和未启用状态仍由原有标签表达。
- 桌面与窄屏下判断摘要没有高度变化、文字裁切或横向溢出。
- 展开与收起后的滚动锚点行为没有变化。

## 验收标准

- 判断摘要颜色由所属卡片的 `--model-surface-accent` 决定。
- 不同子模型保留不同判断摘要色相，但使用同一派生公式和视觉强度。
- 卡片背景与判断摘要不再维护互相冲突的颜色来源。
- Markov 判断摘要与父卡片同属琥珀色系，但视觉上不被误读为警告。
- Bayes 卡片与判断摘要保持紫色表面一致性。
- 模型数据图形、真实状态语义和业务逻辑保持不变。
- 浅色、深色和响应式布局均无视觉或交互回归。
