# UID 绑定页单抬头设计

## 目标

让 UID 绑定页与登录 / 注册页共享同一种卡片抬头语言，同时避免伪造可点击页签或开户步骤条。

## 已批准方案

- UID 绑定页顶部只显示一个居中的全宽“绑定 UID”抬头。
- 抬头使用登录 / 注册活动页签相同的字号、字重、行高、字距、底部间距和深色 1px 下划线。
- 抬头使用语义化 `<h2>`，不可点击，不使用 `tab`、步骤条或返回图标。
- 删除内容区重复的“绑定游戏 UID”大标题。
- “首次进入需要绑定一个游戏账号。”移到抬头下方并保持左对齐。
- UID 字段、提示、主按钮、底部“返回登录”、busy、错误和焦点逻辑保持不变。
- 登录 / 注册页面、登录框外框、页面切换动画和认证流程保持不变。

## 响应式与主题

- 抬头始终占满卡片内容宽度，窄屏不换成双栏或滚动页签。
- 颜色、字体和间距只复用现有 `--terminal-*`、字体角色和排版 token。
- 深色主题继续通过现有语义 token 自动适配，不增加独立色值。

## 验收

- UID 页面只有一个可见标题“绑定 UID”。
- 抬头不是按钮，且不存在页签或步骤条语义。
- 抬头几何与认证页活动页签一致。
- 只有登录框内部的 UID 页面视觉发生变化。
