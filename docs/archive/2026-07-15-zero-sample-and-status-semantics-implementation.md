# 零样本体验与统一状态语义实施记录

## 结果

- 统计诊断与模型评估改用同一套样本成熟度：零样本为中性“待录入”，有样本后依次为“起步观察 / 初步观察 / 可作参考 / 稳定观察 / 可优化权重”。
- 真实计数、未计算指标与语义状态分开显示；全局零样本置信度和评估未形成指标使用半角 `--`，不会附带 `%`、`pp` 或其他单位。
- 工作台保留直接录入路径，并增加紧凑的首次录入说明与“规则基线 · 尚未使用个人样本”来源说明。
- 统计零样本隐藏偏差结果，以 `0 / 500`、阶段轴和返回工作台动作为唯一主要任务。
- 评估在后端进入 `ready` 前隐藏完整回测模块，正文单独显示有效回测 `evaluated_count / 20`；样本成熟度与评估准备度不再混用。
- 空历史面板只在没有保存偏好且没有可见历史时默认最小化；用户已有偏好优先。
- 统计与评估改为按进入页面刷新，档位点击不等待分析请求；账号切换会使旧请求结果失效。
- 浏览器验收发现并修复了全局摘要置信度 prop 只接收数字、而实际 API 返回等级字符串的问题；修复后没有新的 Vue 告警。

## 代码边界

- `WuwaFrontend/src/shared/sampleExperience.js` 是跨页面成熟度、阶段、评估准备度和未计算指标的唯一 owner。
- `SampleReadinessPanel.vue` 与 `InsightRequestState.vue` 分别负责业务准备状态和请求 loading/error；准备面板的桌面 CTA 固定在首行，窄屏恢复单列布局。
- `workspaceInsightRefresh.js` 负责按页刷新、保留最后一次成功数据和旧账号请求失效；`useDashboardNavigation.js` 只做导航编排。
- `WorkspaceSummary.vue` 负责全局摘要的 loading、error、zero 与 ready 呈现。
- 统计与评估 feature 继续拥有各自文案和已有结果模块，未把页面实现回填到 `App.vue`。

## 真实页面验收

使用现有本地开发 UID（286 条样本）检查了：

- 1440 × 900 浅色统计与评估：状态胶囊、阶段范围、`pp` 单位、统计阶段轴和评估三任务模块均正常，无页面级横向滚动。
- 800px 浅色与深色统计：页头摘要自然换行，阶段轴保持可读，深色表面层级和中性文字清晰，无页面级横向滚动。
- 520px 浅色统计与评估：页面无横向滚动，统计阶段轴使用内部横向滚动，评估命中范围和融合权重保持卡片边界。
- 导航焦点具有可见 outline；修复后检查到的新增页面 error/warn 日志为 0。

当前开发 UID 已有 286 条样本。为避免伪造数据或修改用户数据，本次没有生成零样本视觉基线截图，也没有在真实页面执行“零到第一条”及 `evaluated_count` 为 1–19 的状态转换。以上分支由共享纯函数边界测试、页面源码契约测试和组件响应式规则覆盖；仍建议在可安全使用的新 UID 上补一次人工端到端验收。
