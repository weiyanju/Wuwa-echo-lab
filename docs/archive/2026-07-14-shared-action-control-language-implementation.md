# 共享操作控件语言统一实施记录

## 背景

`DESIGN.md` 将普通操作按钮定义为 `12px` 控件圆角和 `44px` 基准高度，并把全圆角胶囊保留给导航、筛选与状态类控件。实施前，`controls.css` 中的共享操作按钮仍统一使用 `100px` 圆角，危险与下一步按钮的最小高度仅为 `38px`，悬停时还包含上浮和带色投影，与当前设计入口不一致。

## 实施范围

- 仅调整共享操作按钮族：主要、购买、次要、幽灵、危险和下一步按钮。
- 将操作按钮圆角统一为 `12px`，高度统一到至少 `44px`。
- 收敛水平内边距，使不同按钮类型保持一致的控件密度。
- 移除悬停上浮和危险、下一步按钮的带色投影，保留原有颜色反馈。
- 不修改任何颜色值、字体角色或页面结构。
- 导航、筛选、UID 切换器和状态标签继续使用全圆角胶囊，不扩大本次调整范围。

## 设计判断

本次修改不是为了机械消除圆角或动画，而是恢复明确的组件语义：操作按钮使用稳定、可点击的软矩形轮廓，胶囊形状继续表达导航、筛选与状态。这样既保留项目已有视觉语言，也避免所有控件都呈现相同的胶囊外观。

浏览器对照结果显示：修改前所有共享操作按钮计算圆角均为 `100px`，按钮高度在 `38px`、`44px` 和 `46px` 之间不一致；修改后六类按钮均为 `12px` 圆角和 `44px` 高度，明暗主题下原有颜色保持不变。

## 回归保护

设计状态测试新增以下约束：

- 共享操作按钮使用 `12px` 圆角和 `44px` 最小高度。
- 共享操作按钮的过渡属性不再包含位移。
- 危险与下一步按钮悬停态不再使用正向带色投影。
- 顶部导航和 UID 切换器仍保持 `100px` 胶囊圆角。

## 验证结果

- 针对性设计测试：10/10 通过。
- Web 全量测试：225/225 通过。
- Vite 生产构建：通过。
- 浏览器明暗主题计算样式与截图对照：通过；按钮几何统一，颜色未改变。
