# 应用外壳与共享控件暗色主题 token 收敛实施记录

## 背景

作为本轮基础颜色治理的最后一个组件族，对应用外壳和共享控件中的暗色主题值进行语义收敛。主题 token 的源定义保持不变，外壳、UID 切换器、顶部导航、Hero 与共享控件改为消费这些定义。

## 实施范围

### 应用外壳

- 面板底色改用 `var(--surface-soft)`。
- 主要文本改用 `var(--ink-deep)`。
- 辅助文本改用 `var(--charcoal)`，弱化文本改用 `var(--steel)`。
- UID 展开态和当前操作文本改用 `var(--primary-deep)`。
- 覆盖 UID 切换器、最近账号、顶部导航、品牌文字与 Hero 指标。

### 共享控件

- 产品面板底色改用 `var(--surface-soft)`。
- 标题、正文、说明和标签改用对应文本 token。
- 主操作渐变与复选框强调色改用 `var(--primary)`。
- 下一步按钮文本改用 `var(--primary-deep)`。
- 六个暗色主题源值在 `controls.css` 中各保留唯一一次定义，使用处不再重复硬编码。

## 回归保护

新增设计状态测试，要求：

- `shell.css` 不再直接引用已映射的五个暗色基础值。
- `controls.css` 中六个主题源值各只出现一次。
- 外壳和共享控件继续实际消费文本、表面与主色 token。

## 验证结果

- 针对性设计测试：9/9 通过。
- Web 全量测试：224/224 通过。
- Vite 生产构建：通过。
- 浏览器计算样式：顶部栏、UID 切换器、导航、Hero、标题、辅助文本、按钮和复选框在迁移前后逐项完全相等。
