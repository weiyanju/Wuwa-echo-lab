# 历史面板暗色主题 token 收敛实施记录

## 背景

按设计治理规范继续对历史面板进行逐组件族整理。本阶段保持历史面板现有状态色和视觉层级，只把与全局暗色主题定义完全同值、同义的基础颜色迁移到语义 token。

## 实施范围

- `#17232d` 改为 `var(--surface-soft)`，覆盖浮动面板底色和滚动条边界。
- `#98aab7` 改为 `var(--steel)`，覆盖记录数量、条目说明和空状态。
- `#e7eef4` 改为 `var(--ink-deep)`，覆盖激活筛选、激活操作和记录标题。
- `#8dc3ff` 改为 `var(--primary-deep)`，覆盖当前筛选与操作悬停文本。
- 保留待处理、已完成、已丢弃等业务状态的专属颜色，以及历史条目深层背景色。

## 回归保护

新增历史面板暗色主题 token 测试，验证四组已迁移颜色不再以原始值出现在 feature CSS 中，同时锁定全局暗色 token 的源值。

## 验证结果

- 针对性设计测试：8/8 通过。
- Web 全量测试：223/223 通过。
- Vite 生产构建：通过。
- 浏览器关键计算样式：迁移前后完全相等。
- 浏览器前后全页截图字节数：完全相等。

## 设计边界

本阶段没有修改筛选状态语言、阴影、透明度、布局或交互，只完成基础主题颜色的语义归属；业务状态色仍由历史面板自身维护。
