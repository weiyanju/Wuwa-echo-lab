# UID 菜单低频退出页脚实施记录

## 背景

UID 菜单此前把账号行、“添加 UID”和“退出登录”连续表现为三个同宽圆角块，即使退出文字改为居中，三个操作仍显得权重接近。用户确认保留完整宽度的添加入口，同时把退出操作降为独立、靠右的低频页脚命令。

## 实施结果

- 将 `.uid-switcher` 设为定位容器，使下拉菜单右边缘锚定 UID 胶囊，不再跟随包含主题按钮的外层操作区。
- “添加 UID”继续保持至少 44px 高和完整宽度，虚线边框改为弱蓝实线，保留弱蓝底色与居中文字。
- 新增 `uid-switcher-footer` 语义中性容器，用贯穿宽度的 1px 分隔线和 8px 顶部内边距区分账号管理内容与退出操作。
- “退出登录”改为页脚右侧 88px 最小宽度、44px 高的透明文字命令，使用 13px / 500 排版；默认无可见边框和底色，hover / focus-visible 才显示弱危险文字与背景。
- 明暗主题保持相同结构，并分别使用现有系统的蓝色、中性色和危险状态色。
- 未修改账号选择、新增 UID 校验、确认提交、退出事件、菜单关闭或焦点恢复逻辑。
