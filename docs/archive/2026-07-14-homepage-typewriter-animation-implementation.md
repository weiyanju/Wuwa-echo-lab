# 首页完整字素打字机动画实施记录

## 实施结果

- 首页标题改为按完整 Unicode 字素逐帧显示，不再使用宽度裁切，因此动画过程中不会出现半个汉字。
- 蓝色光标成为独立行内元素，并跟随当前文字末端。
- 桌面端认证卡片等待标题完成后挂载；等待期间不进入焦点顺序、指针命中区域或无障碍树。
- 减少动态效果、520px 及以下窄屏和页面后台状态直接完成标题并显示认证卡片。
- 登录、注册、校验、账号保存、提交和后续 UID 绑定数据流未改变。

## 工程落点

- `titleAnimation.js` 负责字素分割、时序、完成、取消和计时器失败回退。
- `useTitleAnimation.js` 负责 Vue 生命周期、媒体查询、页面可见性和监听清理，避免继续加厚 `LoginView.vue`。
- `LoginView.vue` 只消费当前标题与完成状态，并以条件挂载控制认证卡片可用时机。
- `auth.css` 只处理独立光标和 160ms 卡片进入过渡，不再动画化标题宽度或裁切属性。

## 验证

- 前端完整测试通过：233 项通过，0 失败。
- Vite 生产构建通过：70 个模块完成转换。
- 桌面端浏览器以 50ms 间隔采样，依次观察到标题的完整字素前缀；所有帧均合法，没有半字，完整无障碍名称保持稳定。
- 认证卡片显隐时序通过：标题未完成时 DOM 中不存在认证卡片，完整标题出现后卡片才挂载。
- 浏览器交互通过：登录与注册切换、账号输入跨模式保持、空表单本地校验均正常。
- 390px 窄屏浏览器检查通过：完整标题与认证卡片立即显示，光标隐藏，标题自然换行，`scrollWidth === clientWidth`。
- 浏览器控制台无 warning 或 error；验收结束后已停止临时 Vite 进程。
- 减少动态效果、页面后台完成、计时器失败与组件清理由自动化测试和源码契约覆盖；当前浏览器运行环境不会在新建验收标签页时改变 `document.hidden`，因此没有将后台切换记录为浏览器实测结果。
