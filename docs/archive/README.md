# 历史资料归档说明

`docs/archive/` 用于保存已经完成阶段使命、仅作为背景参考的历史资料。

归档资料可以包括：

- 已完成 milestone 的执行计划
- 旧方案设计
- 阶段性调研记录
- 已被长期规范吸收的临时说明
- 不再作为当前默认入口的历史 prompt 或 spec

规则：

- 顶层 `docs/` 只保留当前有效的长期规范。
- 新增长期规则应写入顶层对应规范文档。
- 新增阶段性或历史性资料应优先放入 `docs/archive/`。
- 归档资料不能覆盖顶层长期规范。
- 如果归档资料与顶层长期规范冲突，以顶层长期规范为准。

当前 `docs/superpowers/plans/` 和 `docs/superpowers/specs/` 仍保留为既有阶段资料位置。后续整理历史资料时，应逐步迁移或索引到 `docs/archive/`。
