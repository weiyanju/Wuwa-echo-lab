# 工作台暗色主题 token 收敛实施记录

## 背景

继评估页之后，按同一套零视觉漂移原则整理工作台暗色主题。此次迁移继续以当前项目视觉为准，只复用全局暗色主题中已经存在且值完全相同的语义 token。

## 实施范围

- `#e7eef4` 改为 `var(--ink-deep)`，覆盖主要文本、已记录档位和进度文本。
- `#a9bac7` 改为 `var(--charcoal)`，覆盖辅助文本、记录胶囊和记录计数。
- `#98aab7` 改为 `var(--steel)`，覆盖弱化说明、序列标题和空状态。
- `#17232d` 改为 `var(--surface-soft)`，覆盖工作台面板、禁用选项和滚动条边界。
- `#8dc3ff` 改为 `var(--primary-deep)`，覆盖当前声骸圆点和当前记录位置。
- 保留工作台专属的模型提示色、危险操作色、成功状态色和深层组件背景，避免把不同状态语义错误合并为全局 token。

## 回归保护

- 新增工作台暗色主题 token 使用测试，并锁定全局 token 的源值。
- 同步更新禁用声骸成本按钮测试，使其验证语义 token，而不是重复锁定十六进制实现细节。
- 迁移前后通过浏览器夹具逐项比较面板、主要文本、辅助文本、激活选项、禁用选项、记录档位、当前圆点、标题、记录信息、序列信息、空状态和进度文本的计算样式。

## 验证结果

- 关键浏览器计算样式对象：迁移前后完全相等。
- 针对性测试：25/25 通过。
- Web 全量测试：222/222 通过。
- Vite 生产构建：通过。

## 说明

浏览器夹具首轮截图与迁移后截图的文件大小不同，原因是首轮字体资源就绪时机不同；颜色、背景、边框、尺寸等用于本次迁移验收的计算样式全部相等，因此没有把截图文件大小作为本阶段的通过条件。
