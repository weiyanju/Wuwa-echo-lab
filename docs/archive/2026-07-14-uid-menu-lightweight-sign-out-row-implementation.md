# UID 菜单轻量退出行实施记录

## 最终决策

用户在比较分隔线纯文字与弱底色圆角菜单行后，明确要求将“退出登录”改回之前的轻量菜单行。该决策覆盖同日早先恢复分隔线纯文字样式的记录。

## 实际变更

- “退出登录”改为 40px 高、12px 圆角、12px 水平内边距的同宽轻量菜单行。
- 浅色默认态使用中性文字、透明边框和 `rgba(82, 102, 117, 0.05)` 弱底色。
- 浅色 hover / focus-visible 使用弱危险边框、危险文字和 `rgba(228, 30, 63, 0.07)` 弱危险底色。
- 暗色默认态使用透明边框和 `rgba(255, 255, 255, 0.05)` 弱白底；hover / focus-visible 使用弱危险边框、文字和背景。
- 保持纯文字和 `role="menuitem"`，不新增图标，不修改退出事件。
- UID 数据排版、账号行、输入框、确认按钮、新增入口、菜单定位及业务逻辑均未修改。
