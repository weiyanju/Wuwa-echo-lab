# UID 菜单退出项居中实施记录

## 背景

轻量“退出登录”菜单行使用了同宽弱底色容器，但文字仍沿用左对齐，视觉上更像普通表单项，不能稳定表达独立账号操作。用户确认将文字改为水平居中，其他 UID 菜单修改保持不变。

## 实施结果

- 将 `.uid-switcher-sign-out` 的 `text-align` 从 `left` 调整为 `center`。
- 保留 40px 高度、12px 圆角、12px 水平内边距、中性弱底色及 hover / focus-visible 弱危险状态。
- 未修改 UID 选择、新增 UID、确认按钮、暗色主题结构、菜单定位或业务行为。
- 同步 `DESIGN.md` 与 UID 菜单操作层级设计规范，明确轻量菜单行文字水平居中。
