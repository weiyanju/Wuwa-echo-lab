# 评估子模型“最高命中”徽标移除实施记录

## 目标

移除子模型回测行标题后的可见“最高命中”胶囊，减少与绿色命中率、进度条和卡片状态的重复表达。

## 实施内容

- 删除最高命中模型名称后的可见徽标。
- 保留 `isBest` 计算、排序、绿色命中率、绿色进度条和父表面状态。
- 在 disclosure 按钮的无障碍名称中保留“本组最高命中率”，避免状态只依赖颜色。
- 将通用 `em` 徽标样式收窄到 `disabled-model-badge`，并为浅色和深色主题保留中性未启用状态。

## 业务与数据边界

未修改 API、数据库、模型算法、命中率计算、Loss、模型排序、融合权重或展开交互。
